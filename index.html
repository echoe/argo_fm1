Argo

Argo is a multi-engine synthesizer firmware for the M-VAVE FM-1, built on Felucca. It adds eight sequences per track that you can swap between live (and chain), a preset swap on any step, a generative arpeggiator, playable chord modes and more synth engines. It takes the sampling engines out.

InstallConnect your FM-1 by USB and install from Chrome or Edge. There is nothing to install on your computer. EditorEdit patches and projects, and back up the whole FM-1, from the browser. The installer can put M-VAVE's own firmware back (“Return to official V15”), and M-Bootloader is worth installing first, so that you can always reflash.
